المقارن المالي — نسخة Yahoo Finance 2.2
========================================

هذه النسخة لا تستخدم Google Sheets أو Google Apps Script، ولا تحفظ البيانات المالية التي يدخلها الزائر.
تُحسب النسب داخل المتصفح، ويُرسل رمز الشركة فقط إلى خدمة خلفية على Vercel لجلب البيانات.

التغييرات في الإصدار 2.2
------------------------
- إضافة مؤقت 15 ثانية بين كل طلب جلب وآخر من Yahoo.
- يظهر العد التنازلي داخل زر الجلب.
- يستمر المؤقت بعد تحديث الصفحة على الجهاز والمتصفح نفسيهما.
- إزالة اختيار القطاع وجميع المتوسطات والمقارنات القطاعية.
- إزالة حقل الفترة المالية من الإدخال اليدوي ومن واجهة النتائج.
- عند الجلب التلقائي تختار الخدمة أحدث قائمة مالية سنوية مكتملة متاحة.
- يبقى الإدخال اليدوي وحساب النسب متاحين دون مؤقت.

طريقة النشر الموصى بها
----------------------
1) ارفع مجلد المشروع كاملًا إلى GitHub، بما فيه مجلدا api وlib وملف package.json.
2) لا ترفع مجلد node_modules إن كان موجودًا على جهازك.
3) افتح Vercel واختر Add New Project ثم استورد مستودع GitHub.
4) اترك إعدادات البناء الافتراضية واضغط Deploy.
5) بعد النشر، اكتب رمز شركة سعودية مثل 2222 واضغط "جلب البيانات".

مهم: يمكن حفظ المشروع وتحديثه عبر GitHub، لكن ميزة جلب البيانات لن تعمل على GitHub Pages وحده؛ لأن مجلد api يحتاج بيئة خادم. استخدم رابط Vercel لمشاركة الموقع.

كيف تعمل التعبئة التلقائية
-------------------------
- يحوّل الرمز 2222 إلى 2222.SR تلقائيًا.
- يجلب أحدث قائمة مالية سنوية مكتملة والبيانات السابقة اللازمة للحساب عند توفرها.
- يعبّئ الحقول المتاحة ويُظهر الحقول الناقصة بوضوح.
- يعرض العملة ونسبة اكتمال الحقول ورابط المصدر.
- تبقى جميع الحقول قابلة للتعديل قبل الحساب.
- Yahoo Finance مصدر خارجي وقد يفرض حظرًا مؤقتًا أو يعيد بيانات ناقصة؛ لذلك يجب مراجعة الأرقام مع القوائم الرسمية.

المؤقت
-------
- يبدأ المؤقت عند إرسال طلب فعلي إلى Yahoo.
- لا يبدأ عند كتابة رمز غير صالح.
- يمنع طلبًا جديدًا لمدة 15 ثانية ويعرض الوقت المتبقي على الزر.
- الإدخال والحساب اليدويان لا يخضعان للمؤقت.
- المؤقت محلي لتنظيم الاستخدام على الجهاز، وليس نظام حماية مركزيًا بين جميع المستخدمين.

صفحة دليل النسب
----------------
- يفتح زر "استكشف المؤشرات" صفحة ratios.html.
- تشرح الصفحة معنى كل نسبة مستخدمة في النتائج، وطريقة حسابها، وفائدتها، وكيفية قراءتها.

تنبيه

النتائج تعليمية وتحليلية وليست توصية استثمارية. تحقّق من القوائم والإعلانات الرسمية قبل اتخاذ أي قرار.
